## Formation of Present Ātmanepada Participle

The participle of the Present Ātmanepada is formed by adding @deva[आन] to the root which undergoes the same changes before it, as before the termination @deva[अते] or @deva[अन्ते] of the 3rd plural present.

### @deva[आन] → @deva[मान] Substitution

@deva[आन] is changed to @deva[मान] in the case of roots of the 1st, 4th, 6th and 10th classes, and all derived roots — or rather, when the base ends in @deva[अ], before which the @deva[अ] of the base remains unchanged.

### Examples

| Root (Class) | Participle | Meaning |
|--------------|------------|---------|
| @deva[एध्] (1) | @deva[एधमान] | growing |
| @deva[वन्द्] (1) | @deva[वन्दमान] | saluting |
| @deva[शी] (2) | @deva[शयान] | lying down |
| @deva[द्विष्] (2) | @deva[द्विषाण] | hating |
| @deva[हन्] with @deva[आ] (2) | @deva[आघ्नान] | killing |
| @deva[धा] (3) | @deva[दधान] | holding |
| @deva[हु] (3) | @deva[जुह्वाण] | sacrificing |
| @deva[दिव्] (4) | @deva[दीव्यमान] | playing |
| @deva[सु] (5) | @deva[सुन्वान] | extracting |
| @deva[तुद्] (6) | @deva[तुदमान] | giving pain |
| @deva[रुध्] (7) | @deva[रुन्धान] | obstructing |
| @deva[कृ] (8) | @deva[कुर्वाण] | doing |
| @deva[तन्] (8) | @deva[तन्वान] | stretching |
| @deva[क्री] (9) | @deva[क्रीणान] | buying |
| @deva[चुर्] (10) | @deva[चोरयमाण] | stealing, etc. |

### Derived Forms

@deva[बुध्] (1 cl.) cau.: @deva[बोधयति]—@deva[बोधयमान] 'causing to know'

Desiderative: @deva[बुबोधिषति]—@deva[बुबोधिषमाण] 'being desirous to know', etc.
